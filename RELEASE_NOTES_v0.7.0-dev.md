# Diligent Code Studio v0.7.0-dev Release Notes

## Development focus

v0.7.0-dev begins the First Run Setup Wizard improvement track.

## Added

- First Run Setup Wizard layout replacing the older welcome-only onboarding overlay.
- Interface mode selection directly inside the first-run wizard.
- AI provider preference selection directly inside the first-run wizard.
- Default workspace path entry inside the first-run wizard.
- Clear dependency setup path from the wizard to Setup & Dependencies.
- Updated internal version labels to v0.7.0-dev.

## Preserved

- Manual button remains the documentation access point.
- Setup remains available from the top toolbar and wizard.
- No top Guide Me button is restored.
- No duplicate "What this page does" area is restored.
- v0.7.0-dev clean workflow and CI protections remain the baseline.

## Not yet complete

- This is not a final v0.7.0 release.
- The wizard still uses the existing local preferences system.
- Full dependency status indicators inside the wizard are planned but not complete.
