## v0.6.4 Guided Onboarding + User Experience Upgrade

Diligent Code Studio v0.6.4 makes the software easier for new users to understand without requiring someone to sit beside them. It adds a first-run Welcome Wizard, a Start Here workspace, screen-specific guidance cards, a Guide Me button, Beginner/Advanced guidance modes, and sample project shortcuts.

### Quick test

```powershell
npm ci
npm run validate
npm run build
```

For the native desktop build on a machine with Rust/Cargo installed:

```powershell
npm run check:rust
npm run tauri:build
```
