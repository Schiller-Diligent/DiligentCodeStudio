# Diligent Code Studio v0.5.5 - Help Button and Built-in PDF User Manual

This release adds built-in user documentation to the application.

## Added

- Top-right Help button in the main app bar.
- Built-in PDF manual viewer overlay.
- Open PDF action for systems that support opening the manual in a separate PDF-capable viewer.
- `public/manuals/DiligentCodeStudio_UserManual_v0.5.5.pdf` included for app access.
- `docs/DiligentCodeStudio_UserManual_v0.5.5.pdf` included for source package access.

## Notes

- Compact AI Help remains available on every screen.
- The terminal remains limited to the dedicated Terminal page.
- The Help manual does not require an internet connection.
