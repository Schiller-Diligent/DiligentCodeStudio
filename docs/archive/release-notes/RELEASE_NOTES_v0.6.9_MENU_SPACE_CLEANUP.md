# Diligent Code Studio v0.6.9 - Menu Space Cleanup

## Summary
Version 0.6.9 removes the duplicate **Setup & Dependencies** button from the main Workspace Menu because Setup is already available from the top-right app controls.

## Changes
- Removed **Setup & Dependencies** from the default Workspace Menu order.
- Kept the top-right **Setup** button for quick access to Setup & Dependencies.
- Filtered older saved menu preferences so previously stored `setup` entries are removed automatically after upgrade.
- Kept the Setup page fully functional and accessible through top-right Setup and guided onboarding links.
- Preserved Workspace Menu drag-and-drop ordering and Reset Menu Order behavior.
- Added a v0.6.9 addendum to the cumulative PDF manual.

## Expected Result
The Workspace Menu has more horizontal room and should be more likely to fit on one line without hiding key focus areas.
