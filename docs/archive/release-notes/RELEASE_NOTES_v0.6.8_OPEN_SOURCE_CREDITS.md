# Diligent Code Studio v0.6.8 - Open Source Credits

## Added

- Added an **Open Source Credits** Workspace Menu page.
- Added user-visible acknowledgments for frameworks, libraries, developer tools, Rust crates, AI tooling, web-building components, and deployment tools used by or supported in Diligent Code Studio.
- Added clickable **Visit** buttons that open project websites in the user's default browser using the existing Tauri `open_external_url` command.
- Added Open Source Credits access from the Start Here and first-run onboarding flows.
- Added `docs/OPEN_SOURCE_CREDITS.md`.
- Added a v0.6.8 cumulative manual addendum.

## Notes

The Open Source Credits page is an acknowledgment page. It does not replace legal review of dependency licenses, third-party notices, or distribution requirements.
