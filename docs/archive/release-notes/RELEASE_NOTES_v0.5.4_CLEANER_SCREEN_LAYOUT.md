# Diligent Code Studio v0.5.4 - Cleaner Screen Layout

This release removes the always-open global Terminal/Workbench panel from every screen.

## Changes

- Terminal is no longer displayed globally at the bottom of every page.
- Terminal remains available from the dedicated Terminal workspace button.
- Problems, Release Builder, Logs, and AI output remain available on their own pages.
- Compact AI Help remains available on every screen.
- Main workspace pages now have more usable vertical space.
- Version bumped to 0.5.4.

## Validation

Validated with `npm ci` and `npm run build`.
