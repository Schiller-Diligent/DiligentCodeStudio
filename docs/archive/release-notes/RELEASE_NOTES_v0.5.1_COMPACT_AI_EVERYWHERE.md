# Diligent Code Studio v0.5.1 Compact AI Everywhere

This release keeps AI available on every screen while making it much less intrusive.

## Changed

- Replaced the large right-side AI section with a compact floating AI helper.
- AI can be minimized to a small bottom-right **AI Help** button.
- AI can be expanded only when help is needed.
- Main workspace now keeps the full available width.
- AI works from every screen: Editor, Setup & Dependencies, Tool Registry, Project Health Dashboard, Terminal, Git, Release, Settings, and Logs.
- Quick actions remain available for explaining files, finding bugs, reviewing errors, reviewing terminal output, summarizing Git, and navigating the current screen.

## Validation

Validated with `npm ci` and `npm run build`.
