# Diligent Code Studio v0.6.10 UI and Manual Cleanup

This package update applies two requested cleanup items:

- Removed the on-page **What this page does** guide card and its duplicate **Guide Me** button from the workspace page area.

The top toolbar **Guide Me** action has now also been removed. Users can still open **AI Help** from the top toolbar when they want assistant support.
